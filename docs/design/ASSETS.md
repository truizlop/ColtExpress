# Original production assets

Created with the built-in Imagegen tool. Prompts requested original Western editorial woodcut art on parchment, no copied publisher artwork.

- portraits.png: six evenly spaced circular character portraits, 3 columns x 2 rows; Cheyenne, Django, Belle / Tuco, Doc, Ghost.
- actions.png: six evenly spaced square vignettes, 3 columns x 2 rows; running between train cars, climbing a ladder, shooting / punching, taking a purse, marshal badge. No UI text.
- desert.png: panoramic painted Arizona mesas, pale blue sky, muted apricot cliffs and open cream sand foreground. No train or characters, intended behind the live 3D scene.

Concepts are visual direction references. Required deviations: all game pieces are actual Three.js models as explicitly requested by the user; action cards and labels are live HTML; opponent purse values hidden; correct legal hand sizes, cards and events.
