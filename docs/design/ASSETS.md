# Original production artwork

All illustrations are original assets generated with Imagegen, not publisher scans. PNG masters are retained here; production WebP files preserve their full dimensions and transparency. Encodings are the only image processing used.

| Asset in public/art      | Role                                                                         | Source                               |
| ------------------------ | ---------------------------------------------------------------------------- | ------------------------------------ |
| wordmark.webp            | Transparent engraved title and concept tagline                               | docs/artwork/wordmark.png            |
| portraits-comic.webp     | Six circular comic portraits, Cheyenne / Django / Belle / Tuco / Doc / Ghost | docs/artwork/portraits-comic.png     |
| actions-transparent.webp | Move / climb / shoot / punch / loot / marshal vignettes                      | docs/artwork/actions-transparent.png |
| card-back.webp           | Printed sheriff-star card back                                               | docs/artwork/card-back.png           |
| materials.webp           | 2x2 wood, paper, iron, sand material atlas                                   | docs/artwork/materials.png           |
| desert.webp              | Painted Arizona panorama                                                     | docs/artwork/desert.png              |
| card-frame.svg           | Native vector double-line ticket border                                      | source asset                         |

Earlier portraits and action masters remain as the design history. Live UI copy, card titles, counts and actions are HTML. A subtle cream wash reduces paper contrast; action illustrations use transparency and multiply blending. The desert sits behind a transparent WebGL canvas. Atlas textures supply wood/metal grain and bump detail to real geometry. Train, track, meeples, loot and scenery are procedural Three.js models, an intentional and required departure from the concept's static illustrated train. Tiny prop lettering uses a runtime texture; no official artwork is included.
