# Rules reference

Implementation edition: Ludonaute 2016 English rules, advanced base game with character powers and round events. The two-player game uses the revised two-bandit rules: three cars plus locomotive, select one card then draw six (seven with Doc), standard-turn Shoot may cover a different bandit's non-Marshal card, and team Gunslinger ignores friendly shots. This intentionally differs from the 2014 two-player expert variant.

Official sources inspected visually:
- https://www.data.ludonaute.fr/Colt_Express/RULES/Colt_Express_Rules_2016_EN.pdf
- https://www.data.ludonaute.fr/Colt_Express/CONTENTS/CARDS/Colt_Express_Cards_BACK.pdf (despite filename, contains faces; round schedules pp. 110–126)
- https://www.data.ludonaute.fr/Colt_Express/SPREAD_DISPLAY/Colt_Express_6WAGONS_Train.png (printed floor counts)

Car profiles (purses, jewels): baggage (1,0), second class (1,1), first class (0,3), dining (3,0), mail (4,1), private saloon (3,1). Total 12 purses and 6 jewels. Car subset and order are seeded random choices, permissible under setup rules.

Neutral bullets: if there are too few for a group encountering the Marshal or an event, nobody in that group receives one. Forced movement still applies. Empty gun or no legal target never consumes ammunition. Belle is excluded only when another legal target exists; she still blocks roof line of sight. Players may shoot their own teammate in the two-player game. All six powers are active.

Values of purses once personally seen are remembered if the token changes possession. Starting $250 purses are public knowledge. Unknown token values never enter AI observations. Future rounds and deck order remain hidden.

The 2016 expert variant is optional for 3–6 players: deck recycling, retained cards and public discards. The default is standard deck reshuffling each round.
